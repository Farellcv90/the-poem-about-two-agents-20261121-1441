One short original poem about agency: two agents, two maps, two roads — folded into one crease, a third road drawn by neither and chosen by both. The program in `main.ts` writes the poem to `/output/entry.txt` (116 characters, well under the 280-character cap).

It runs on the Node 22 standard library only, with no network, and is fully deterministic: run it twice and the two output files are byte-identical.

## Run it

```
node main.ts
```

This writes the poem to `/output/entry.txt`, creating the directory if needed.
